# 🎓 Интерактивный тренажёр по программированию (1 курс)

> Создано для студентов специальности **«Разработка и управление программным обеспечением»**  
> Дисциплина: **«Алгоритмизация и программирование»** (СПбГУПТД, кафедра ЦАТ).

Этот проект — локальная обучающая платформа, созданная для того, чтобы помочь одногруппникам самостоятельно и уверенно освоить материалы семестра: от базовых команд Git до продвинутого бинарного поиска.

---

## 🚀 Быстрый старт (Запуск в 1 команду)

Для работы **не нужно ничего устанавливать** через `pip` — всё работает на чистом Python 3 из коробки:

```bash
# 1. Посмотреть список всех тем и уроков
python tutor.py list

# 2. Получить свой персональный вариант задания
python tutor.py variant "Твоё Имя Фамилия" 3

# 3. Проверить своё решение
python tutor.py test 3

# 4. Пройти проверочный квиз по теме
python tutor.py quiz 3
```

---

## 🚦 Три уровня сложности в каждом уроке

У всех в группе разный уровень подготовки. Поэтому каждый урок разделён на 3 уровня:

| Уровень | Файл решения | Для кого | Что внутри |
| :--- | :--- | :--- | :--- |
| 🟢 **С нуля (`base`)** | `exercise_base.py` | Для тех, кто впервые видит код и только учится | Простые жизненные аналогии, пошаговые `TODO`, разжеванные подсказки |
| 🟡 **Стандарт (`standard`)** | `exercise_standard.py` | Университетская норма кафедры ЦАТ | Точные требования методичек преподавателя, валидация ввода, краевые случаи |
| 🔴 **Профи (`advanced`)** | `exercise_advanced.py` | Для ребят с опытом и подготовкой | Повышенная сложность: оптимизация памяти $O(1)$, рекурсия, олимпиадные бонусы |

Проверить конкретный уровень можно флагом `--level`:
```bash
python tutor.py test 6 --level base        # Режим для новичка
python tutor.py test 6 --level standard    # Стандартная практика
python tutor.py test 6 --level advanced    # Уровень профи
```

## 🛡️ Как устроена защита от списывания?

Мы хотим, чтобы каждый реально научился писать код, а не просто копировал чужие ответы:
1. **Персональные варианты (`python tutor.py variant <ФИО> <номер>`)**:
   На основе вашего имени детерминированно генерируются уникальные числа, диапазоны и условия задачи. Списать у соседа по парте не имеет смысла — у него другие числа.
2. **Рандомизированные тесты (Fuzzing)**:
   При проверке тренажёр прогоняет ваш код через 50 случайных тестов. «Захардкодить» ответы через `if x == 73: print(...)` не получится.
3. **Трёхуровневые подсказки (Progressive Hints)**:
   - `python tutor.py hint <номер> 1` — идея и наводящий вопрос (без кода).
   - `python tutor.py hint <номер> 2` — алгоритм и псевдокод по шагам.
   - `python tutor.py hint <номер> 3` — подробный разбор эталонного кода с пояснением "зачем так сделано".
4. **Контрольный квиз (`python tutor.py quiz <номер>`)**:
   Интерактивные вопросы на понимание логики работы алгоритмов.

## 📚 Каталог уроков

- **[01_git_basics](lessons/01_git_basics/)** — Git: первые шаги, `git init`, `add`, `commit`, `diff.txt`, `log.txt`.
- **[02_git_branching](lessons/02_git_branching/)** — Git: ветвление, создание веток, вызов и разрешение конфликта слияния.
- **[03_python_input_conditions](lessons/03_python_input_conditions/)** — Ввод данных, `isdigit()`, ветвления `if/elif/else`, високосный год, площади фигур (формула Герона).
- **[04_algorithms_and_flowcharts](lessons/04_algorithms_and_flowcharts/)** — Алгоритмы, ГОСТ 19.701-90 блок-схемы, Теорема Бёма — Якопини, цикломатическая сложность.
- **[05_arrays_and_lists](lessons/05_arrays_and_lists/)** — Массивы и память, формула адресации, списки `list`, in-place разворот списка за $O(1)$ памяти.
- **[06_binary_search](lessons/06_binary_search/)** — Бинарный поиск $O(\log n)$, пошаговая трассировка, теоретический максимум шагов $\lceil\log_2(n+1)\rceil$.
