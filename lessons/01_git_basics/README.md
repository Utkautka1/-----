## 🧭 Зачем нужен Git? (Объяснение на пальцах)

Представь, что ты пишешь курсовую работу и сохраняешь файлы:
`проект.py`, `проект_исправленный.py`, `проект_финал.py`, `проект_ТОЧНО_ФИНАЛ_НЕ_ТРОГАТЬ.py`.
В итоге никто не знает, где актуальная версия, а если что-то сломалось — вернуть рабочий код назад невозможно.

**Git** — это распределённая система контроля версий (VCS). Она работает как **машина времени** для твоего кода:
1. Делает «слепки» (коммиты) проекта в важные моменты.
2. Показывает точную разницу (`diff`): какая строчка была добавлена, а какая удалена.
3. Позволяет мгновенно вернуться к любой точке в прошлом, если что-то пошло не так.

## 🚦 Уровни прохождения урока

### 🟢 Уровень 1: «С нуля» (Базовый)
Если ты впервые открыл терминал:
1. Запусти терминал в своей рабочей папке.
2. Создай папку проекта: `mkdir my_project && cd my_project`.
3. Инициализируй репозиторий: `git init`.
4. Создай файл `README.md` с описанием проекта: `echo "# Мой первый проект" > README.md`.
5. Сделай первый коммит:
   ```bash
   git add README.md
   git commit -m "Первый коммит: добавлен README"
   ```

### 🟡 Уровень 2: «Практик» (Требования университетской работы)
Согласно методичке `Git начало`:
1. Создать репозиторий `project`.
2. Создать `README.md` и сделать коммит с осмысленным сообщением.
3. Изменить `README.md`, выполнить `git diff` и сохранить вывод в `diff.txt`:
   ```bash
   git diff > diff.txt
   ```
4. Закоммитить изменения `README.md` и файл `diff.txt`.
5. Посмотреть историю `git log` и сохранить вывод в `log.txt`:
   ```bash
   git log > log.txt
   ```
6. Сделать 3-й коммит с файлом `log.txt`.

### 🔴 Уровень 3: «Профи» (Бонусные задания)
1. Настроить локальный `.gitignore` для игнорирования мусорных файлов (`__pycache__`, `.DS_Store`, `.venv`).
2. Посмотреть сокращённый лог с хэшами: `git log --oneline`.
3. Отправить репозиторий на GitHub в свой приватный или публичный профиль.

## 🧪 Проверка выполнения
В корне тренажёра запусти:
```bash
python tutor.py test 1 --level standard
```
Тренажёр автоматически проверит наличие созданного репозитория, файлов `README.md`, `diff.txt`, `log.txt` и число коммитов.
