## 💡 Теоретическая справка: Ввод и Ветвления

### 1. Как работает `input()`?
Функция `input()` **всегда** возвращает строку (`str`), даже если пользователь ввёл `42`!
Чтобы производить математические операции, строку необходимо преобразовать:
```python
year_str = input("Введите год: ")
year = int(year_str)  # преобразует в целое число (int)
radius = float(input("Радиус: "))  # преобразует в дробное число (float)
```

### 2. Защита от дурака (Валидация ввода)
Если пользователь вместо числа введёт буквы, например `"двадцать"`, вызов `int()` вызовет ошибку `ValueError` и программа аварийно завершится.
Для проверки целых положительных чисел используется метод строки `.isdigit()`:
```python
if not user_input.isdigit():
    print("Ошибка: нужно ввести целое число!")
```

### 3. Правило високосного года
Год является високосным, если:
1. Он делится на 4 **И** не делится на 100, **ИЛИ**
2. Он делится на 400.
```python
is_leap = (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
```

### 4. Неравенство треугольника и формула Герона
Треугольник со сторонами $a, b, c$ существует тогда и только тогда, когда **каждая сторона строго меньше суммы двух других**:
$a < b + c$ и $b < a + c$ и $c < a + b$.

Площадь по формуле Герона:
$$p = \frac{a + b + c}{2}$$
$$S = \sqrt{p \cdot (p - a) \cdot (p - b) \cdot (p - c)}$$
