## 📐 Что такое алгоритм и зачем нужны схемы?

**Алгоритм** — это точная и понятная последовательность действий, приводящая от исходных данных к результату за конечное число шагов.

### Свойства алгоритма:
1. **Дискретность**: разделение на отдельные шаги.
2. **Детерминированность (определённость)**: при одинаковых входных данных результат всегда одинаковый.
3. **Понятность**: команды входят в систему команд исполнителя.
4. **Результативность (конечность)**: алгоритм должен завершиться за разумное число шагов.
5. **Массовость**: применим к целому классу аналогичных задач.

---

## 🏛️ Теорема Бёма — Якопини (1966)
Любой сколь угодно сложный алгоритм может быть реализован с использованием всего **трёх базовых конструкций**:
1. **Следование (линейная структура)**: выполнение команд друг за другом.
2. **Ветвление (`if / else`)**: выбор одной из двух ветвей по условию.
3. **Цикл (`while / for`)**: повторение блока действий, пока истинно условие.

## 📊 Основные символы ГОСТ 19.701-90

| Символ | Название | Что обозначает в программе |
| :--- | :--- | :--- |
| **Скруглённый прямоугольник** | Терминатор | Начало и конец алгоритма («Пуск», «Останов») |
| **Параллелограмм** | Данные | Ввод (`input()`) и вывод (`print()`) |
| **Прямоугольник** | Процесс | Вычисление (`s = a * b`), присваивание |
| **Ромб** | Решение | Условие (`if a > b`), ветвление Да / Нет |
| **Предопределённый процесс** | Процедура | Вызов сторонней функции (`binary_search()`) |
