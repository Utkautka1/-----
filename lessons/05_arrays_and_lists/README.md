## 🧠 Как устроен массив в оперативной памяти?

Представь шкаф с пронумерованными ячейками. Каждая ячейка занимает ровно 4 байта.
Если массив начинается по адресу `1000`, то адрес элемента с индексом `i`:
$$\text{address}(i) = \text{base\_address} + i \times \text{size\_of\_element}$$
Процессору не нужно перебирать элементы по порядку — он мгновенно вычисляет адрес по одной математической формуле. Именно поэтому операция `arr[i]` занимает **$O(1)$ (константное время)**!

## ⚖️ Массив против Связного списка (Linked List)

| Характеристика | Непрерывный массив / `list` | Связный список (Linked List) |
| :--- | :--- | :--- |
| **Память** | Лежит сплошным блоком | Разбросан по куче, хранит указатели `next` |
| **Доступ по индексу `[i]`** | **$O(1)$** — мгновенно | **$O(n)$** — нужно идти от начала |
| **Вставка в начало** | $O(n)$ — сдвиг всех элементов | **$O(1)$** — просто поменять ссылку головы |
| **Добавление в конец** | Амортизированное $O(1)$ (`append`) | $O(1)$ при наличии указателя `tail` |
